# 本地发布检查

以下步骤均在本机完成。发布目标为已具备 .NET Framework 4.8+ 的 Windows 10/11；运行用户无需 .NET SDK、Node.js 或额外下载。

## 构建和自动检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

- 核心检查通过：ISO 周数和日期边界、旧数据迁移、各周独立保存、周切换、日常模板生成与完成重置、任务排序、原子保存及损坏恢复。
- 打印检查通过：七等宽列、按天编号、字体与颜色、完整任务框、蓝色完成标记、硬边距及密集任务无截断；所选周页眉正确，其他周和旧记录数据不显示。
- 控件集成检查通过：上一周、下一周、日历和回到本周；编辑后切换、跨周撤销隔离、每日复制、完成置顶、未提交空白项不写盘、保存恢复及 PNG 编码。
- 检查跨列拖拽的预览与最终任务样式、换行和序号一致；取消拖拽和切周后无遗留浮层。
- 检查七个底部清空区域等宽且初始隐藏，悬停显示、移出隐藏；确认框显示所选周具体日期，默认不清空，确认只影响该天，并可撤销。
- 以不同于系统本周的日期导出，确认页眉及默认文件名使用所选周，月余和年余仍按当前日期计算。
- 检查 `artifacts/tests/board-preview.png`、`artifacts/tests/print-preview.png` 和 `artifacts/tests/exported-board.png`；预览不是发布版自带示例数据。
- 最终版本、构建大小及实际检查结果记录在 `VALIDATION.md`，不沿用旧版数量或旧窗口行为。

自动测试通过不代表已测试每种输入法、显示器或物理打印机。原生 IME 选词、滚动长列拖拽、跨列放置、Esc 取消，以及实际纸张输出需按本次发布的实际验证情况记录；未执行的检查明确保留为未验证。

## 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1
```

- `dist/TaskBoard-1.2.1-portable.zip`：只放运行所需的 `TaskBoard.exe`、`TaskBoard.exe.config`、`README.txt` 和 `LICENSE`。
- `dist/TaskBoard-1.2.1-source.zip`：包含源代码、构建和打包脚本、图标资源、测试及说明；排除 `artifacts`、`qa-data`、`dist`、`.git`、缓存和本地用户数据。
- `dist/SHA256SUMS.txt`：列出两个 ZIP 的 SHA-256；以 `Get-FileHash -Algorithm SHA256` 本地复核。
- 程序图标嵌入可执行文件；图标源文件随源码包保留。
- 不执行上传、Git push、远程发布或自动下载；不把测试任务复制到用户默认数据目录。

## 解压后的运行核对

1. 将便携包解压至独立目录，确认程序与配置文件同目录；运行发布版不需要开发工具。
2. 使用 `TaskBoard.exe --data-dir "隔离测试目录"` 检查全新数据和再次打开，避免写入日常使用的看板。
3. 确认窗口约为可用屏幕宽高的 70%，七天标题、任务框和序号正常，底部没有记录区。
4. 编辑中英文和颜色、标记完成、创建日常任务；切换到另一周再返回，确认任务、完成状态及顺序独立保留。
5. 打开尚无归档的未来周，确认仅继承更早已知周的日常任务，完成状态重置；未保存过的过去周应为空。关闭并重开后检查归档仍存在，默认显示本周。
6. 导出所选周 PNG 并重新打开，确认包含周日末条任务，不含其他周任务或旧记录数据；检查打印对话框的 A4 横向设置，实际出纸后核对边距和颜色。
7. 使用含旧 `recordFields` 的隔离数据检查升级：原字段仍保留在文件中，界面、图片和打印均不显示。
8. 确认 `board.json` 和 `board.backup.json` 只出现在选定数据目录；便携包与源码包中均无该次测试数据。

需要保护或迁移数据时，先关闭应用，再复制整个数据目录。发布包更新程序文件，不应删除 `%LOCALAPPDATA%\TaskBoard`。

`deploy.ps1 -DestinationRoot "D:\TaskBoardRelease" -Update -Prune` 会先备份旧程序和源码，再移除已知旧源文件、旧发布包和多余备份，保留一组回退文件及自定义文件。原程序被占用时先尝试移入本次备份；仍无法移动时，将新版另存为 `TaskBoard-<版本>.exe`，不结束正在运行的进程。关闭旧窗口再打开新文件，仍使用同一份本地任务数据。
